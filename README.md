# makefun-mend

mend, one patch tool for every AI edit format, built for make.fun's [Build mend, one patch tool for every AI edit format](https://make.fun/bounty/hidden-spec-cli-01-run-20261122) bounty. `main.ts` reads a patch in unified diff, SEARCH/REPLACE, V4A or JSON form, matches the lines it names at the first of three tiers (exact, trailing-whitespace, full-whitespace), and applies every change or none.
